# Legado

Exercícios das primeiras fases, guardados como histórico. Nenhum deles faz parte do app atual (API em `server.ts` + interface em `web/`).

| Pasta | O que é |
|---|---|
| [`prototipo-html/`](prototipo-html) | Página estática da primeira fase (HTML semântico + Tailwind via CDN, dados fixos, sem chamar a API) |
| [`meu-primeiro-app/`](meu-primeiro-app) | Primeiro app React com Vite (Aula 05 e 06): `useState`, componentes `Botao` e `Tarefa`, lista em memória. `App_v01.jsx` é a versão inicial (lâmpada liga/desliga) |

Para rodar o `meu-primeiro-app`:

```bash
cd legado/meu-primeiro-app
npm install
npm run dev
```
